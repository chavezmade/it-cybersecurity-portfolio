# Valentino Chavez — IT & Cybersecurity Portfolio

A personal portfolio website for the AWS Student Builder Challenge, featuring an interactive, browser-based Linux-style terminal.

## Features
- Responsive dark-themed portfolio
- About, technical skills, and hands-on project sections
- Functional interactive terminal with commands such as `help`, `about`, `skills`, `projects`, `ls`, and a discoverable hidden command
- Accessible navigation and keyboard-friendly terminal

## Technologies
HTML, CSS, vanilla JavaScript, GitHub, and AWS Amplify Hosting.

## Deploy on AWS Amplify
1. Push `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
2. In AWS Amplify Hosting, choose GitHub and select this repository's `main` branch.
3. For a plain HTML/CSS/JS site, no build command is needed; set the output directory to `/` if prompted.
4. Review settings and possible AWS charges, then deploy.
5. Test the public URL, including the terminal commands.

## Creative feature
The interactive terminal simulates common Linux commands. Visitors see a hint and can discover a hidden command by exploring `ls` and `cat secret.txt`. No shell commands are actually executed.

## Project notes
Project summaries describe educational practice and experience. Supporting lab screenshots and documentation will be added later. No passwords, private lab credentials, or AWS keys should be uploaded.
